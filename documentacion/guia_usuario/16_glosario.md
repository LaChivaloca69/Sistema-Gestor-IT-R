# 15. Glosario breve

| Término | En esta aplicación significa |
|---------|------------------------------|
| Folio | Identificador que el sistema asigna al ticket, la solicitud, la orden o la bitácora. |
| Check | Seguimiento formal de un ticket. Puede cerrarlo si incluye la solución. |
| Campana | Icono de avisos del encabezado. |
| Cobertura | Un técnico suplente atiende los tickets de un compañero ausente. |
| Kit | Periféricos vinculados a un equipo padre. |
| Consumible | Insumo controlado por cantidad, no por número de serie. |
| En stock | Equipo disponible para asignar. |
| SLA | Tiempo máximo interno de atención según la prioridad del ticket. |
| Bitácora | Nota interna de TI. No es el ticket del empleado. |
| Gobierno | Funciones para administrar accesos, permisos, plantillas e historial. |
| Operativo | En el manual de negocio: Técnico IT o Administrador en tareas de piso. |
| Personal | Ficha del empleado. Puede estar vinculada a la cuenta con la que entra. |
